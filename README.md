# Base de Datos SPAFEU

## Requisitos

- PostgreSQL 17 o superior.
- Base de datos `spafeu_db` creada.
- El comando `psql` disponible.

## Instalación

Desde la carpeta `release/0.0.1` ejecutar:

install.bat

Si no desea usar el script, ejecutar los archivos en este orden:

1. 01_types.sql
2. 02_schema.sql
3. 03_import.sql
